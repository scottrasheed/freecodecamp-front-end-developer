# Camper Cafe Menu

I built a café menu with HTML and CSS while working through freeCodeCamp’s 89-step Café Menu workshop. The menu lists coffees and desserts with prices and uses a centered layout that adapts to the width of the screen.

## Open locally

1. Keep `index.html` and `styles.css` in the same folder.
2. Open `index.html` in a browser.

There’s nothing to install. The coffee bean background and menu icons load from freeCodeCamp’s CDN.

## Project files

- [`index.html`](./index.html) contains the menu sections, items, prices, and footer.
- [`styles.css`](./styles.css) controls the layout, typography, spacing, and link colors.
