# Accessibility Quiz

I built an HTML and CSS quiz as part of freeCodeCamp’s 67-step Accessibility Quiz workshop. It includes a student information section, two true-or-false HTML questions, a CSS dropdown, and a text area for questions. I practiced making forms easier to navigate with descriptive headings, connected labels, and grouped answer choices.

## Open locally

Keep `index.html` and `styles.css` in the same folder, then open `index.html` in a browser. There’s nothing to install. You can try the navigation and form controls locally. Use sample data if you click **Send**, since the form posts to the workshop’s endpoint.
