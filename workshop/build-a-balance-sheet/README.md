# Balance Sheet

I built a balance sheet for the fictional AcmeWidgetCorp as part of freeCodeCamp’s 66-step Balance Sheet workshop. It shows assets, liabilities, and net worth from 2019 to 2021. I practiced using semantic HTML tables and CSS selectors to keep the figures easy to compare.

## Open locally

Keep `index.html` and `styles.css` in the same folder, then open `index.html` in a browser. There’s nothing to install. Scroll down to see the year bar stay in view, and hover over a total row to see it highlight.
