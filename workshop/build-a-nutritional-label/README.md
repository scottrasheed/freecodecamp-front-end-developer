# Nutrition Facts Label

I built a Nutrition Facts label with HTML and CSS as part of freeCodeCamp’s 68-step Nutrition Label workshop. It displays serving sizes, calories, nutrient amounts, and Daily Value percentages. The workshop helped me practice using typography and spacing to make dense information easy to scan.

## Open locally

Keep `index.html` and `styles.css` in the same folder, then open `index.html` in a browser. There’s nothing to install. The label uses Open Sans from Google Fonts and falls back to a system sans-serif font when offline.
