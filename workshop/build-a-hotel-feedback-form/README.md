# Hotel Feedback Form

I built an HTML form for hotel guests to share feedback as part of freeCodeCamp’s 33-step Hotel Feedback Form workshop. It collects basic guest information, asks about the stay, and lets guests rate the service and food.

## Open locally

Open `index.html` in a browser. There’s nothing to install. You can try the form controls and browser validation locally. Use sample data if you submit the form, since it sends the entered values to the workshop’s form endpoint.
