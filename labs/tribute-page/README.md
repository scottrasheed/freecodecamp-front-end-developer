# Dr. Norman Borlaug Tribute Page

A tribute to Dr. Norman Borlaug, an agricultural scientist whose work on wheat helped increase food production. The page includes a photograph, a short timeline of his life, and a link to his biography.

This project passed freeCodeCamp’s **Build a Tribute Page** lab.

## Run locally

1. Keep `index.html` and `styles.css` in the same folder.
2. Open `index.html` in your browser.

The page uses HTML and CSS. An internet connection is required to load the photograph from freeCodeCamp.

## Design and accessibility

- Semantic HTML organizes the page into a main section, headings, a figure, and a timeline.
- The photo has alternative text for screen reader users and a visible caption that provides context.
- The photo stays centered and scales down on narrow screens while keeping its proportions.
- The biography link opens in a new tab.
