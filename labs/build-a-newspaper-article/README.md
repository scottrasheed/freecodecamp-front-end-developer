# The Neighborhood Gazette

A single-page newspaper article built with HTML and CSS for freeCodeCamp’s Responsive Web Design curriculum. The sample story covers a community garden opening downtown.

## What I Practiced

- Structuring an article with semantic HTML, headings, a byline, and paragraphs.
- Setting font families and fallbacks with `font-family`.
- Using `rem` for the newspaper name and `em` for the headline and sub-headline.
- Adjusting paragraph spacing with `line-height` and `text-indent`.
- Styling the opening letter of each paragraph with `::first-letter`.

## Run Locally

Keep `index.html` and `styles.css` in the same folder, then open `index.html` in your browser. The project requires no build step.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | Contains the article and links to the stylesheet. |
| `styles.css` | Defines the fonts, text sizes, spacing, and first-letter styling. |
