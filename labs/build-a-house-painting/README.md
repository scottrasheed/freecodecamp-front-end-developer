# Sunset Cottage

I built a house illustration with HTML and CSS for freeCodeCamp’s Build a House Painting lab. I chose peach walls, a plum roof, golden windows, and a teal door for a warm sunset palette.

## Open locally

Keep `index.html` and `styles.css` in the same folder, then open `index.html` in a browser. There’s nothing to install.

<details>
<summary>Show lab notes</summary>

The numbered comments in [index.html](./index.html) and [styles.css](./styles.css) show how I addressed the lab’s user stories.

| Steps | What I practiced |
| --- | --- |
| 1–5 | Building the house structure and setting its size, border, and background |
| 6–11 | Using absolute positioning to place the roof, windows, and door |
| 12–13 | Moving the chimney above the roof and layering it with `z-index` |

I also used CSS gradients to draw the window frames and a pseudo-element to make the doorknob.
